# React Shopping Cart

## Objective

Develop a React Shopping Cart application using:

- React
- useState()
- map()
- Event Handling
- Array methods

## Requirements

1. Use useState() to store the cart.
2. Use map() to display all products.
3. Display:
   - Product name
   - Price
   - Quantity
4. Add + button to increase quantity.
5. Add - button to decrease quantity.
6. Calculate the total amount dynamically.
7. Use a unique key while rendering products.
